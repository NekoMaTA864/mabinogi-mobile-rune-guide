# 瑪奇 Mobile｜多功能工具站

[開啟線上工具站](https://nekomata864.github.io/mabinogi-mobile-rune-guide/) · [研究來源](sources.md)

純功能性、免登入、零個人資料儲存的《瑪奇 Mobile》台服多功能靜態工具站（Phase 1～3 已全部上線）。

### 五大主分頁功能
1. **即時排程（首頁）**：台灣時間（UTC+8）即時時鐘、每日／每週一 06:00 重置、野外首領（12/18/20/22 點）與每小時整點不詳的召喚結界倒數、今日週幾地下城高亮與動態黑洞追蹤站快連。
2. **符文中心（S1／S0 雙賽季）**：
   - 依職業查配裝（6 系列整齊 2×3 單排矩陣、2×2 四象限、雙職共用金框高亮、懸停效果浮窗、分享連結）。
   - S1「10 格試配檢核器」（自動檢查重複裝備、團本唯一衝突、缺陷與神話「永恆」抵銷、覺醒覆蓋、異常來源與 8★ 飾品符文之語）。
   - 反查符文／全圖鑑（S1 150 顆＋30 組別名；S0 104 顆台服正式名）與 S1 機制／16 組符文之語對照表。
3. **物資與計算**：
   - 以物易物雙向快查（24 條提爾克納／杜巴頓常用路線）與每日／每週 NPC 商店倍數金幣試算。
   - 寶石合成與星光稜晶 S 計算機（同階 3 合 1 晉階展開＋9/9 改版直合星光稜晶材料試算）。
   - 交易所德卡手續費正反算（預設 15% 稅率，支援售價→實領淨利與目標實領→損益兩平最低掛單價）。
4. **版本未來視**：台韓改版時間軸對照、未開放新轉職（暗黑術士／騎士）定位與一鍵跳轉配裝、S1→S2 銜接規劃與時裝時間軸入口。
5. **社群工具箱**：依 6 大分類整理 20 個中文社群網站＋5 款純靜態計算／查表工具站內沙盒預覽工作台。
