# 瑪奇 Mobile 全職業 S1 符文指南

[開啟符文指南](https://nekomata864.github.io/mabinogi-mobile-rune-guide/) · [研究來源](sources.md)

純功能性、免登入的瑪奇 Mobile Season 1 全職業（六系 21 職）符文查詢工具。

### 主要功能
- **依職業查配裝**：預設收合，點選任一職業以 2×2 四象限（左上武器、右上徽章、左下飾品、右下防具；列＝T0／T1／T2）檢視推薦；支援「並排顯示韓文」、「複製配裝文字」與「複製分享連結」。
- **雙職並排比較**：可同時對照兩個職業，並以金框自動高亮「共用符文」，方便規劃跨職共用裝或評估轉職。
- **反查符文／全圖鑑**：收錄全站 150 顆 S1 符文，支援以繁中名稱、社群常見別名、韓文原名或效果關鍵字（暴擊、破防、冷卻、缺陷、覺醒、燃燒、冰凍等）快速反查「這顆符文哪些職業用得到」，並可一鍵跳轉該職四象限配裝。
- **懸停效果浮窗**：滑鼠移至（手機點擊）任一符文即時顯示詳細中文效果、對應技能、缺陷副作用、韓文原名與全職採用數。
- **S1 機制與符文之語速查**：白星 vs 黃星換裝提醒、核心關鍵字速懂與 16 組 8★ 飾品符文之語對照表，另提供深色／淺色模式切換。

下載後可直接開啟 `index.html`，將 `runes.js` 放在同一目錄。資料以 Git 維護，無須登入或外部同步。
