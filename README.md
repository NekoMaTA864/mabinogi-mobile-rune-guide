# 瑪奇 Mobile｜S1 多功能工具站

[開啟線上工具站](https://nekomata864.github.io/mabinogi-mobile-rune-guide/) · [研究來源](sources.md)

純功能性、免登入、零個人資料儲存的《瑪奇 Mobile》台服 S1 多功能靜態工具站（已套用 `frontend-design` 與 `web-design-guidelines` 美編與無障礙規範）。

### 目前功能模組（Phase 1 + Phase 2 已上線）
1. **符文中心**：
   - **依職業查配裝**：六系 21 職預設收合，2×2 四象限（左上武器、右上徽章、左下飾品、右下防具；列＝T0／T1／T2），支援雙職共用金框高亮、並排韓文、複製配裝與分享連結。
   - **10 格試配檢核器**：自由選配 1 武器＋1 徽章＋3 職業飾品＋5 防具（支援一鍵套用 T0 預設），即時自動檢核重複裝備、團本巨神碎片「唯一」防具衝突、缺陷副作用與神話「永恆」抵銷、覺醒套組聯動、燃燒／冰凍異常來源、T0–T2 吻合度與 8★ 飾品符文之語進度，並支援專屬連結分享。
   - **反查符文／全圖鑑**：150 顆 S1 符文＋30 組跨站社群別名＋效果關鍵字反查與一鍵跳轉。
   - **S1 機制與符文之語**：白星 vs 黃星重點、關鍵字速懂與 16 組 8★ 飾品符文之語表。
2. **以物易物（純查表與金幣試算）**：
   - 提爾克納／杜巴頓常用以物易物雙向查詢（找投入材料 ⇄ 找目標產物），依城鎮與用途（3 級設計圖、催化劑與聖水、生活材料、戰鬥消耗品）快速篩選。
   - 每日／每週商店必買優先度與多角色倍數金幣試算（不儲存任何個人庫存或進度）。
3. **即時排程（台北時間 UTC+8）**：
   - 每日 06:00／每週一 06:00 重置、野外首領（12/18/20/22 點）與每小時整點不詳的召喚結界即時倒數、今日週幾地下城高亮與動態黑洞追蹤站快連。
4. **社群工具箱**：
   - 20 個中文社群網站分類檢索目錄＋5 款純靜態計算／查表工具之站內沙盒預覽工作台。
