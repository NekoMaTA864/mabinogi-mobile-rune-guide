# 瑪奇 Mobile｜S1 多功能工具站

[開啟線上工具站](https://nekomata864.github.io/mabinogi-mobile-rune-guide/) · [研究來源](sources.md)

純功能性、免登入、零個人資料儲存的《瑪奇 Mobile》台服 S1 多功能靜態工具站。

### 目前功能模組（Phase 1 已上線）
1. **符文中心**：
   - **依職業查配裝**：六系 21 職預設收合，點選後以 2×2 四象限（左上武器、右上徽章、左下飾品、右下防具；列＝T0／T1／T2）顯示；支援雙職並排與共用符文金框標示、並排韓文、複製配裝與分享連結。
   - **反查符文／全圖鑑**：收錄全站 150 顆 S1 符文，支援繁中名、30 組社群別名、韓文原名與效果關鍵字反查採用職業，並可一鍵跳轉。
   - **懸停效果浮窗**：滑鼠懸停（手機點擊）顯示中文效果、對應技能、缺陷副作用、韓文原名與全職採用數。
   - **S1 機制與符文之語**：白星 vs 黃星換裝提醒、核心關鍵字速懂與 16 組 8★ 飾品符文之語對照表。
2. **即時排程（台北時間 UTC+8）**：
   - 每日 06:00／每週一 06:00 重置倒數、野外首領（12/18/20/22 點，含前 10 分鐘預先入場與進行中提示）、不詳的召喚結界（每小時整點）即時倒數。
   - 今日「週幾地下城」高亮與一週完整對照表，以及動態黑洞即時回報站快連。
3. **社群工具箱**：
   - 收錄 20 個中文社群網站與工具（依符文／黑洞／物資製作／MML／新手／桌面工具分類搜尋）。
   - 內建「站內沙盒工具工作台」，支援 5 款純靜態計算／查表工具站內預覽（均附原作者出處與新分頁開啟降級鈕）。

### 檔案結構（免建置工具、純靜態 GitHub Pages）
- `index.html`、`styles.css`：共用外殼與淺／深色主題樣式。
- `runes.js`、`data/schedule.js`、`data/tools-catalog.js`：符文、排程與社群目錄資料。
- `modules/rune-center.js`、`modules/timer-board.js`、`modules/toolbox.js`：三大主分頁功能模組。
