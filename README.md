# 瑪奇 Mobile 全職業 S1 符文指南

[開啟符文指南](https://nekomata864.github.io/mabinogi-mobile-rune-guide/) · [研究來源](sources.md)

六系 21 職，含韓服 S1 後續加入的騎士與暗黑術士。選職業後以 2×2 四象限分區（左上武器、右上徽章、左下飾品、右下防具）檢視各部位 T0／T1／T2 推薦，點選同一職業可收合。

所有符文已補上繁體中文名稱（社群常用譯名或暫譯），滑鼠移至或點擊任一符文即可顯示詳細效果、對應技能、缺陷副作用與韓文原名，方便直接比對台服遊戲圖鑑；另提供「並排顯示韓文原名」切換鈕。

下載後可直接開啟 `index.html`，將 `runes.js` 放在同一目錄。資料以 Git 維護，無須登入或設定同步。
