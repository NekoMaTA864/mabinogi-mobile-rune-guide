1. **即時排程（首頁）**：台灣時間（UTC+8）即時時鐘、愛麗莎紫洞 36 小時 15 分週期與未來 3 場預估、跨例行維護校準提醒、野外首領（12/18/20/22 點）、不祥的召喚結界三段倒數、今日週幾地下城與黑洞追蹤站。
2. **符文中心（S1／S0 雙賽季）**：
   - **S0 賽季零｜S1 開季／過渡｜S1 季末／終局** 三段時間線切換（預設 S1 開季過渡；切季末終局於變動符文顯示極簡 `▲／★／▼` 微標與懸停演變說明）。
   - 依職業查配裝（6 系列整齊 2×3 單排矩陣、2×2 四象限、飾品與技能特化速查條、雙職共用金框高亮、懸停效果浮窗、與職業養成雙向互跳）。
   - S1「10 格試配檢核器」、反查符文／圖鑑（S1 280 顆、S0 110 顆，支援別名搜尋）與 S1 機制／16 組符文之語對照表。
3. **職業養成（全 21 職業・S1 Lv.85）**：
   - **子分頁 1：各職業養成指南（21 職）** — 2×3 六張對稱核心卡：**① 寶石雕琢**、**② 技能特化（飾品符文對應與實戰循環）**、**③ 刻印重設**、**④ 裝備附魔（對齊台服 S1 現有 16 卷：武器／防具／徽章／飾品＋地下城／碎片來源）**、**⑤ 等級卡（1～85 級與 65～85 特殊卡）**、**⑥ 進階養成可選項**。
